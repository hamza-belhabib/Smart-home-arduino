# Smart Home – Arduino

Academic IoT project developed as part of the **Internet of Things (IoT) – S6**
course at Université Ibn Zohr – Faculté Polydisciplinaire de Ouarzazate.

## Overview

A simulated Smart Home system based on Arduino integrating several automated
modules for security, access control and environmental monitoring.

## Features

- Motion detection using a PIR sensor
- Automatic access based on distance measurement
- Temperature monitoring and automatic regulation
- Password-based door access
- Soil humidity monitoring
- Gas detection
- Automatic night lighting

## Technologies

- Arduino
- C / Arduino programming
- Tinkercad Circuits
- Sensors and actuators
- LCD 16x2 / I2C
- Servo motor
- Buzzer and LEDs
